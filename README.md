# DosisDatoAppGEMINI

A simple SwiftUI application. This repository also contains an accompanying `index.html` page with support and privacy policy information.

## Prerequisites

- **Xcode** 15 or later on macOS
- iOS 17 SDK

## Build and Run

1. Clone this repository.
2. Open `DosisDatoAppGEMINI.xcodeproj` in Xcode.
3. Select an iOS simulator or a connected device.
4. Build and run the app using Xcode's **Run** button (or `Cmd+R`).

## `index.html`

`index.html` provides a small website that mirrors the support information and privacy policy from the app. It is not bundled or served by the iOS application but can be hosted separately for reference.

## Limitations and Future Work

The project currently targets **only iOS**. To port to Windows or the browser you could explore frameworks like React Native, Flutter, or simply host the HTML page for web access.
